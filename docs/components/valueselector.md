# ValueSelector

Renders a `<select>` element. This versatile component is used for all controls that allow users to choose a value from a list, including:

* [`combinatorSelector`](/docs/components/querybuilder-controlelements.md#combinatorselector)
* [`fieldSelector`](/docs/components/querybuilder-controlelements.md#fieldselector)
* [`operatorSelector`](/docs/components/querybuilder-controlelements.md#operatorselector)
* [`valueSourceSelector`](/docs/components/querybuilder-controlelements.md#valuesourceselector)

`ValueSelector` also serves as the default `selectorComponent` for [`ValueEditor`](/docs/components/valueeditor.md) when a rule's `value` must be selected from a list.
