# InlineCombinator

Wraps a [`combinatorSelector`](/docs/components/querybuilder-controlelements.md#combinatorselector) component (provided via the `component` prop, defaults to [`ValueSelector`](/docs/components/valueselector.md)) within a `<div class="betweenRules inline-combinator">` container. Used when [`showCombinatorsBetweenRules`](/docs/components/querybuilder.md#showcombinatorsbetweenrules) is enabled or when queries use [independent combinators](/docs/components/querybuilder.md#independent-combinators).
